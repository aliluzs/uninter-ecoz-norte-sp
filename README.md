# 🌿 EcoZ-Norte SP - Guia de Descarte Eletrônico Consciente

> **Projeto Extensionista de Tecnologia**  
> Curso: Análise e Desenvolvimento de Sistemas — **Uninter**  
> Região Foco: Santana, Tucuruvi e Zona Norte de São Paulo  

---

## 📌 Sobre o Projeto

O **EcoZ-Norte SP** é uma aplicação web desenvolvida como atividade extensionista acadêmica. O objetivo é conscientizar a população sobre os riscos do descarte incorreto de lixo eletrônico (e-lixo) e facilitar o acesso a **11 pontos de coleta e ecopontos oficiais** distribuídos na Zona Norte de São Paulo.

---

## 🚀 Funcionalidades

- **Carrossel Interativo:** Navegação entre 11 pontos de descarte cadastrados.
- **Integração com Google Maps:** Atualização dinâmica do mapa conforme o ecoponto selecionado pelo usuário.
- **Design Responsivo (Mobile-First):** Layout adaptado para navegadores desktop e dispositivos móveis.
- **Validação Comunitária:** Formulário integrado (Google Forms) e botão otimizado para coleta de feedback e dados para o estudo acadêmico.

---

## 🛠️ Tecnologias Utilizadas

- **HTML5** (Estruturação semântica)
- **CSS3** (Variáveis, Flexbox, Media Queries e Dark Theme)
- **JavaScript (ES6+)** (Manipulação do DOM e lógica do carrossel/mapa)
- **Google Fonts** (*Sora*, *Lexend*, *Plus Jakarta Sans*)
- **GitHub & Cloudflare Pages** (Controle de versão e deploy contínuo)
